# 分镜多角色音色验收

2026-11-11 14:10（Asia/Shanghai）。交付状态为本地修改。

- 项目分镜以已保存角色顺序加入有效绑定的录音。角色选择、试听和请求预览共用对应关系；手动参考音频保留原顺序，自动加入的音频接在后面。提交时后端重读分镜和角色绑定，避免并发修改后发送用户没有预览的录音。
- 自动引用计入 Seedance 数量、时长和请求体校验以及生成计费输入。新请求只使用当前分镜角色，不会回退到项目的其他角色。音频写入任务素材，进入历史详情和后台恢复路径；重试沿用原任务的音色快照。旧调用方未传新字段时维持原逻辑，历史任务和历史成片没有回填或修改。
- 后端相关测试 71 项通过。隔离 HTTP 集成覆盖登录、Seedance 2.5 的两条自动音频与一条手动音频共存及顺序、未选角色排除、空分镜不回退、预览过期及超时长在预授权前拒绝、数据库重启后任务和历史成片可读。适配器测试以模拟请求确认音频顺序。媒体探测测试使用本机已安装的 FFprobe。
- 前端测试 303 项通过，Vite production build 通过。实际使用 Edge 在 1280×720、1440×900、1920×1080、390×844 验收项目分镜：角色与音频编号、音频播放、预览请求、切镜、角色增删保存、滚动到生成操作和页面尾部。各尺寸页面与音色区域均无横向溢出；窄屏通过「控制」页签进入。内置浏览器初始化超时，agent-desktop 报 Windows 私有文件 DACL 错误，因此改用 Playwright 驱动本机 Edge。
- 验收使用临时数据库、合成 WAV、无效供应商地址和隔离 worker。浏览器只允许本地登录、报价和测试分镜角色更新，禁止创建生成任务；其他无关写请求被夹具拦截。真实模型出片和线上环境未验证。
